#1 Securing and Auditing Long-Horizon LLM Agents: State-Transfer Auditing and Controls in the Agent Harness
agent
著者: Deep Shah, Nehal Kathrotia
公開日: Thu, 19 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.23346
要約:
Long-horizon LLM agents across codebases, web browsers, and enterprise infrastructure rely on an execution harness to move state between the working context, session history, persistent memory, and external environment. While conventional execution traces log model prompts and tool calls, critical security and reliability failures occur during state transfers: a transfer can admit unchecked content (indirect prompt injections, unverified memory writes), rewrite state lossily (context compaction dropping user constraints, memory consolidation stripping source authority), or restore state incompletely (workspace rollbacks leaving aborted KV state active on the inference server). Because current traces omit what crosses these boundaries, failure attribution and runtime monitors fail on multi-step trajectories. We present a state-transfer audit architecture for the agent harness. At each transfer boundary, we define an audit point specifying the minimal hash-chained record the harness emits, separating low-overhead deterministic checks from model-based semantic checks and binding internal context, memory, and inference-server cache state to external actions. We show that the same transfer records required for causal failure attribution supply the durable state needed by runtime security controls, including least-privilege capabilities, replay-resistant authorization outside the prompt, information flow control, obligation monitors, and transactional recovery across multi-agent and infrastructure pipelines. Finally, we analyze multimodal GUI adaptations and implement and evaluate a reference harness middleware across 240 multi-step fault-injection trajectories, showing that transfer records localize root causes and catch cross-transfer violations missed by lifecycle and tool-only logs at microsecond deterministic overhead.
#2 Asymmetric Optical Image Watermarking
intellectual property
著者: Guang Yang
公開日: Thu, 19 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.23350
要約:
Watermark detectors held by a provider cannot be checked by third parties, and a party that can detect a mark can usually also forge it. We study a two-layer image watermark in which the Fourier transform at the core of the pipeline is performed by a coherent optical 4F unit. Layer 1 carries an Ed25519 signature bound to the image content in Fourier magnitudes, so anyone with the public key verifies offline. Layer 2 is a key-defined carrier written by a secret phase hologram and read by a matched-filter correlator. The optics is a scalar-diffraction simulation with finite modulator bits, pixel aperture, pupil, defocus, misalignment, and sensor noise. No hardware is built. All criteria were fixed in a hashed specification before any optical result. The simulated optical signer reproduces the digital pipeline (field error 1.7e-15, bit agreement 99.997%), verifies at least 99.5% of 877 images under each of 8 post-sensor settings, one unattacked, and accepts none of 40,670 unmarked images. The optical carrier is key-selective: the matched key detects it on 99.8% of the unattacked images, and detection falls to 0% under a scale error of 1% and to 0% under a mask shift of 1 bin. Security rests on the signature and the content binding, for which we separate what is provable from what is measured.
#3 Image Watermarking With Memory Across Reissuance
intellectual property
著者: Xinyuan Li, Yi Nian, Xiaoqin Feng, Tiankai Yang, Yue Zhao
公開日: Thu, 19 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.23363
要約:
Publishers often revise and reissue images, yet valid watermarks may persist on superseded releases or unapproved edits. Even a current release can contain regions last authorized at different revisions. We introduce and formalize reissuable provenance: determining an image's current, superseded, or unissued status and recovering each region's last authorized revision (its generation), with abstention when evidence is insufficient. Generational Stratigraphy Fields (GSF) combine watermark evidence with an authenticated live reference to the current release, enabling replacement or retirement without rewriting circulated copies. Each reissue freshly embeds new generation labels in approved regions and inherited labels elsewhere, preserving history without requiring old watermarks to survive successive edits. Our complete-output reissuance evaluation follows 480 histories through four releases, retaining each AI editor's entire output. GSF achieves 99.67% accuracy in classifying issued images as current or superseded and 94.09% recall of unissued edits. After three reissues, one generation map provides time and location: it recovers regional labels with 93.13% median accuracy and localizes the latest approved revision with 92.86% IoU. Regional labels remain readable under tested delivery transformations that impair issued-state recognition. Watermarks can thus express who issued an image, which release is authoritative now, and when each region was last authorized.
#4 Lossless Reversible Watermarking for AIGC with Applications in Authentication

要約:
AIGC watermarking is commonly used for tracing, but it can also support applications such as authentication and tampering detection. We study lossless reversible watermarking, which enables exact recovery of the original watermarked image after permissible distortions. By exploiting the relatively low entropy of the information required for image generation, together with robust latent-space watermarking, we design a framework that preserves sufficient information for lossless recovery. We then apply the framework to AIGC authentication, which generally faces two key challenges. First, the authentication mechanism must resist adaptive adversaries. Second, the content relevant to authentication, such as visual designs or expressed messages, may depend on application requirements that are not known at generation time. To solve these difficulties, we incorporate cryptographic message authentication to provide unforgeability against adaptive attacks. Lossless recovery provides the original image as reference evidence, after which a suitable analyzer can be selected to make the authentication decision. Experiments on Stable Diffusion demonstrate exact recovery under a wide range of distortions.
#5 ACaM: Automated Capability Modeling for Agentic AI Security
agent
著者: Monika Santra, Dhilung Kirat, Qiushi Wu, Kevin Eykholt, Xiaokui Shu, Ian Molloy
公開日: Thu, 19 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.23507
要約:
In agentic AI systems, an LLM invokes tools that hold standing access to credentials, private data, filesystems, and external services. Such agents are increasingly deployed without an answer to a basic question: what can an agent access, exfiltrate, and propagate, independent of what it is designed for or is observed to do? The question goes unanswered because existing approaches trust a tool's natural-language description as a proxy for its behavior. But nothing enforces that the description and its implementation agree. This gap is known as Description-Code Inconsistency (DCI). DCI enables a threat class called capability laundering, in which a tool's implementation contains dangerous behavior that its description omits. The behavior may come from incidental drift or a supply-chain compromise. It runs silently whenever an LLM invokes the tool for its stated, benign purpose. We present ACaM, a neurosymbolic approach to capability modeling that derives each tool's capabilities from its code, so a laundered capability cannot hide behind a benign description. In ACaM, static analysis grounds an LLM in code-derived facts, and no LLM output can override a fact that static analysis has established. The LLM supplies only the behavioral meaning that those facts cannot express. ACaM compiles agent source code into the Agent Capability Property Graph (ACPG) and uses it to reconstruct threat chains that span multiple tool calls. We evaluate ACaM on 43 real-world agents, including 9 multi-agent systems. On 24 manually annotated agents, it recovers capability properties with 98.3% macro-F1 and reconstructs injected threat chains with a score of 0.980, 8 points above the strongest baseline. Applied to all 43 unmodified agents, it discovers hundreds of structural vulnerabilities, ten of which we confirm with proof-of-concept exploits.
#6 A-Tag: Cryptographic File Tagging with Enforced Live Human Presence

リンク: https://arxiv.org/abs/2611.23602
要約:
The increasing autonomy of software agents and the proliferation of AI-generated content have weakened the reliability of digital actions as evidence of human involvement. Existing mechanisms, such as digital signatures and authentication protocols, verify identity and integrity, but do not establish whether a live human was present at the time an action was performed. In this paper, we introduce A-Tag, a system for verifiable human-in-the-loop tagging of digital artifacts. A-Tag cryptographically binds a file to a verified instance of live human presence at the moment of tagging. The resulting tag serves as a persistent and transferable proof that the action was triggered by a live human, without making claims about the origin, identity of the actor, or semantic content of the file. A-Tag is a modular framework combining liveness verification based on micro-motion signals shaped by human motor control, a secure cryptographic binding between the verified event and the artifact, and a publicly verifiable logging mechanism enabling independent validation. We implement A-Tag on commodity devices and evaluate it under realistic conditions. Our evaluation shows that A-Tag provides cryptographically sound artifact binding with deterministic verification, while enabling robust recovery under real-world transformations, achieving over 99 percent success for image-based artifacts, and maintaining sub-second verification and practical tagging latency.

要約:
Web applications have been essential to accessing and managing online services. Made available with weaknesses, much due to their rapid development and human error, they are exposed to frequent web injection attacks, leaving security analysts overwhelmed with threats and alerts that often lack critical details for proper risk assessment. Detecting these attacks requires inspecting the payload of network traffic packets, which becomes inaccessible when traffic is encrypted via HTTPS, as encryption hides the content of the traffic. This paper introduces a Multimodal Artificial Intelligence (AI) system to protect online services that rely on web application security by detecting and classifying web injection attacks, and provides security analysts with information to support attack prevention and incident response. The results demonstrated its ability to accurately identify attacks and their classes, achieving an F_1 score of 91% and an accuracy of 95%, and offering valuable insights for alert prioritisation.
#8 FlowSH: Detecting Web Attacks by Correlating Anomalous Network Flows and Endpoint Logs

公開日: Thu, 19 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.23669
要約:
Web applications compose the core of internet services, rendering them prominent targets for audacious attackers. Among web attacks, SQL injection (SQLi) remains a persistent, damaging web applications connected to databases. The widespread adoption of HTTPS has been a critical advancement for online security, ensuring the confidentiality and integrity of communications by encrypting network payloads. However, it also renders traditional Network Intrusion Detection Systems (NIDS) less effective, as these typically rely on packet inspection of plaintext traffic. To access encrypted payloads, some NIDS resort to TLS-interception proxies, which leads to data leaks and security risks. This paper presents FlowSH, a system for detecting web attacks that is agnostic to whether the traffic is encrypted (HTTPS) or not (HTTP). Rather than decrypting packets in transit, FlowSH correlates flow-level metadata (NetFlows) with endpoint logs, which inherently contain decrypted payloads after reaching the web server. The system combines unsupervised machine learning to flag anomalous NetFlows and similarity search over server-side logs using Locality Sensitive Hashing (LSH) to confirm attacks. We implemented and evaluated FlowSH in a testbed with multiple web scanners and demonstrated its detection effectiveness, detecting 70% of SQLi attacks missed by ModSecurity, a leading web application firewall.
