#1 Exploring Early Vulnerability Analysis via Automatic Identification of Vulnerability-Introducing Commits
著者: Weiliang Qi, Shu Wang, Youpeng Li, Ela Guo, Xinda Wang
公開日: Mon, 23 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.26739
要約:
Developing effective vulnerability analysis techniques requires high-quality datasets that capture how vulnerabilities appear and evolve in real software codebase. Existing datasets, however, typically label as vulnerable only the code immediately preceding vulnerability-fixing commits (VFCs), overlooking the earlier versions in which vulnerabilities were first introduced and subsequently evolved. This practice limits both dataset coverage and our understanding of whether current detectors can identify vulnerabilities during their early, latent stages. In this paper, we present three manually annotated datasets of vulnerability-introducing commits (VICs) based on recent CVEs and widely used open-source projects. We further propose D-SZZ, a data state-aware VIC identification framework that analyzes security-fixing patterns and performs vulnerability scope slicing to recover the semantics implied by a fix. Experimental results demonstrate that D-SZZ outperforms existing SZZ and LLM-based baselines in identifying VICs. In addition, we evaluate six representative vulnerability detectors and find that models trained only on pre-VFC code struggle with original vulnerabilities, while incorporating early-stage samples improves detection performance. We also show that D-SZZ improves downstream vulnerable-version identification, and use it to uncover 16 inaccurate affected-version records in the NVD, all of which were officially confirmed and updated.

A Security Operations Center (SOC) plays a critical role in detecting, correlating, and responding to modern cyber threats. However, SOCs continue to face challenges related to alert overload, fragmented detection capabilities, and limited collaboration between analysts and automated systems. These issues often result in delayed incident response, analyst fatigue, and an increased risk of overlooking sophisticated, multi-stage attacks that unfold gradually across different layers of the network. #3 Extracting Next Generation Access Control Policies from Natural Language Using LLMs: An Intermediate-Representation Approach with Back-Translation Verification
著者: Ayesha Habib, Huixiang Zhang, Waiz Haider
公開日: Mon, 23 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.26941
要約:
Organizations write access-control rules in natural language, but NIST's Next Generation Access Control (NGAC) needs them as a formal policy graph. Large language models (LLMs) can automate this translation, but their output can break the format, add rules the text does not state, or drop conditions. We present NGAC-IR, which follows model-driven engineering (MDE). First, the LLM fills in an intermediate representation (IR), a JSON template that records who may, must or must not do what, on which resource and under which condition; a grammar keeps the output within this template. Second, a compiler that uses no LLM converts the IR into an NGAC policy graph and links each rule to its source sentence. Third, a back-translation check writes each rule in English and asks an LLM whether the source sentence states it. On four public datasets, all outputs could be compiled, compared with 95.5% without the grammar, and 95.7% were faithful to their sentence. NGAC-IR outperforms two published methods on all four datasets: the LLM-based Code4Policy in exact match and faithfulness, and the rule-based extractor of Abdelgawad et al. in rule type. The back-translation check sent 10.5% of sentences to human review and found 26 of the 31 errors. To test enforcement, we deployed the compiled policies in NIST's Policy Machine: they gave the expected decision for all 390 access requests, and the tested obligations were carried out. On one local server with open-weight models, all 714 sentences take about 20 minutes and 0.35 kWh, at zero API cost.

#5 GeoCloak: Defending Against Geolocation Reasoning in Multimodal Language Models via Perceptual Image Editing
著者: Haoyang Xu, Christian Iha, Colbren Fujimoto, Yingfei Dong, Rui Ning, Liuwan Zhu
公開日: Mon, 23 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.26987
要約:
Multimodal large language models can infer sensitive geographic information from ordinary images by combining visual, textual, architectural, and environmental cues. This capability creates a privacy risk: users may reveal fine-grained location information even when explicit metadata such as GPS tags has been removed. We study this problem as geolocation inference in multimodal language models and present GeoCloak, a cue-aware perceptual editing framework for reducing location leakage from shared images. GeoCloak uses an accessible multimodal model as a proxy to identify geolocation-relevant cues, localizes high-impact regions through object grounding, and applies localized semantic edits designed to disrupt downstream geolocation predictions while preserving the overall scene content. These results suggest that cue-level semantic editing is a promising direction for reasoning-based visual privacy, while also highlighting open challenges in deployment cost, semantic plausibility, and adaptive evaluation.
#6 Subverting Tool Arguments: Defense-Evading Metadata Poisoning in LLM Agents

著者: Shih-Chieh Dai, Xinyu Sun, Haichuan Zhang, Zhiyuan Zhong, Guanhong Tao
公開日: Mon, 23 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.27041
要約:
Conventional indirect prompt injection (IPI) attacks hijack an LLM agent's workflow through malicious instructions embedded in retrieved external content. The growing adoption of the Model Context Protocol (MCP) exposes another attack surface: tool descriptions supplied by third-party MCP servers. Attackers can manipulate this metadata to induce malicious argument generation during tool calls. The challenge is to ensure that the modified descriptions still appear benign to both LLMs and users. Existing IPI attacks, however, struggle to achieve both high attack success and low detectability in this setting. To address this challenge, we propose GRAFT, an LLM-based optimization method for crafting adversarial tool descriptions. Specifically, GRAFT uses a masking mechanism to identify argument-relevant token positions for targeted injection. It then iteratively refines candidate descriptions using dynamic mutation strategies proposed by an LLM, guided by the agent's tool choices and generated arguments. We evaluate GRAFT on three public datasets against several attack baselines. The results show that GRAFT achieves higher attack success while maintaining low detection rates across five filter-based defenses. It also bypasses several existing IPI defenses. Even under an adaptive defense trained on GRAFT-generated injections, GRAFT remains more effective than the baselines.

#8 "More Than You Expect!": Leakage-Abuse Attacks on Encrypted Vector Search
著者: Yang Zhang, Ruiqi He, Xiaoqian Sun, Siyi Lv, Zheli Liu
公開日: Mon, 23 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.27174
要約:
Vector databases support semantic search and retrieval-augmented generation, but embeddings, queries, and record labels may contain sensitive information. Although encrypted vector search protects these contents, some schemes expose records retrieved together across queries. We identify semantic neighborhood leakage, whereby co-retrieval relationships derived from access patterns reveal semantic categories of encrypted records and queries. We present SAGE (Semantic Access-pattern Graph Exploitation), a passive, persistent leakage-abuse attack that infers record labels and query categories from access patterns. SAGE builds a weighted co-retrieval graph and offers two variants requiring different auxiliary knowledge. SAGE-Dist matches anonymous spectral groups to semantic categories using estimated class proportions and refines labels via optimal transport, without known record labels. SAGE-Known combines graph-based label propagation with spectral-group anchor voting using a small set of known labels. We evaluate SAGE on four text and image datasets. With 1% known record labels, SAGE-Known achieves up to 84.3% mean record-label accuracy and outperforms the strongest corresponding baselines on all four datasets. With only estimated class proportions, SAGE-Dist achieves 66.9% record-label accuracy and 68.1% query-category accuracy on AG News, exceeding the strongest corresponding baselines by 21.8 and 41.9 percentage points, respectively, though performance varies across datasets. Experiments with a real-world DCPE implementation (Fuchsbauer et al., SCN'22) show that semantic leakage persists under encrypted approximate retrieval. These findings expose privacy risks even when vector contents remain protected.

Fully Homomorphic Encryption (FHE) enables non-interactive, privacy-preserving transformer fine-tuning, protecting highly sensitive data as inputs to large language models. #11 PCC: Proof-Carrying Credentials for Enhanced Anonymity and Post-Quantum Delegation
著者: Zixuan Wang, Zheng Tianyu, Yuan Lu, Bin Xiao

リンク: https://arxiv.org/abs/2611.27250
要約:
Delegatable Anonymous Credentials (DACs) support anonymous exercise of authority delegated through intermediaries, as in DeFi credit delegation. Existing DACs require holders to possess and process chain-shaped lineage material for presentation. We call this limitation \emph{prover awareness}: presentation cost grows with delegation depth, while holder-visible topology can enable lineage-based vetoes, strategic disintermediation, and de facto censorship. We formalize the privacy dimension as \emph{Enhanced Delegation Anonymity} (EDA), a leakage-parametrized two-observer notion combining verifier-side anonymity with holder-side topology obliviousness. We give simulation and indistinguishability formulations over paths with identical allowed holder leakage. Our framework, \emph{Proof-Carrying Credentials} (PCC), addresses both limitations by replacing the explicit chain with a recursively updated proof-carrying state via Non-Uniform Incrementally Verifiable Computation (NIVC). PCC makes presentation independent of delegation depth and hides topology beyond permitted leakage, while preserving restricted delegation and expressive presentation. Unlike pairing-based constant-size DACs, PCC is hardness-agnostic and admits a post-quantum-compatible instantiation in the QROM using transparent FRI-based recursion and hash-based signatures. On consumer-grade hardware, the Halo2 instantiation keeps a constant 7.344\,KB verifier-facing proof with 35--36\,ms verification across all tested depths. The 128-bit Plonky2 instantiation keeps a constant 157.9\,KB proof with 3.8\,ms verification across depths $L\in\{1,2,4,8,16\}$, at 1.03\,s per delegation step. These results demonstrate practical depth-independent presentation and holder-side topology hiding.

#14 Detecting Word-Substitution Poisoning of a RAG Knowledge Base with Relative Entropy and Runtime Verification

公開日: Mon, 23 Nov 2026 00:00:00 -0500
リンク: https://arxiv.org/abs/2611.27410
要約:
A retrieval-augmented generation (RAG) system answers questions using passages it retrieves from a knowledge base, so users must trust that knowledge base. We study an attacker who quietly edits existing passages by swapping words for synonyms (PWWS, TextFooler) in a cybersecurity RAG system built from MITRE ATT&amp;CK and CAPEC. Using a reviewed 44-question benchmark, repeated paired runs and a control corpus in which only the layout changes, we find that poisoning lowers judged answer correctness from 0.714 to 0.555. The damage comes mostly from lost evidence and refusals, not from false statements. To find the edited passages, we use relative entropy. Comparing a whole passage with normal text is a weak signal. Still, one term of the relative entropy, the log-ratio between a word and its most probable synonym, works well: with a small language model as the reference, it reaches an AUROC of 0.95 and stays near chance on the control. Filtering does not restore correctness, because the edited passage is usually the one that held the answer. We therefore add a runtime monitor that checks each answer against trusted MITRE STIX data and remembers the passages it rejects. On its own, it reduces exposure to edited text from 0.41 to 0.26; when it may add the trusted MITRE entry as a source, correctness rises to 0.786. We report the costs and failure cases of every defence alongside its gains.
